# sc player

Десктопный клиент SoundCloud для Windows: лайки, плейлисты и любые публичные профили — без рекламы, в стиле
ночного портфолио [@skythemontage](https://soundcloud.com/skythemontage).

## Установка

1. На странице [последнего релиза](../../releases/latest) необходимо скачать один из файлов:
   - `sc-player-setup-v….exe` — установщик (создаёт ярлыки на рабочем столе и в меню «Пуск»);
   - `sc-player-portable-v….exe` — версия, которая запускается без установки.
2. Приложение не подписано сертификатом, поэтому при первом запуске Windows может показать сообщение
   «Windows защитила ваш компьютер». В этом случае следует нажать **Подробнее → Выполнить в любом случае**.
3. Для доступа к своей библиотеке нужно нажать **Sign in to SoundCloud** и войти в аккаунт SoundCloud
   (email и пароль) — после этого появятся лайки и плейлисты пользователя.
   Без входа можно открыть любой публичный профиль, вставив ссылку вида `https://soundcloud.com/…`.

Для обновления достаточно скачать новую версию и установить её поверх текущей — вход и настройки сохраняются.

## Возможности

- Лайки, плейлисты (собственные и понравившиеся), история прослушивания, поиск треков.
- Профили: треки, лайки и плейлисты любого пользователя; профили можно закрепить в боковой панели.
- Перемотка по вейвформе, очередь с перетаскиванием, перемешивание и повтор.
- Громкость запоминается между запусками.
- Каждая страница сохраняет выбранную вкладку, фильтр и положение прокрутки; разделы боковой панели работают
  как вкладки со своей историей.
- Пока окно свёрнуто или скрыто, анимации полностью останавливаются — продолжает работать только звук.

## Ограничения

- Часть треков SoundCloud отдаёт только в зашифрованном виде (DRM — как правило, монетизированные и
  мейджор-релизы). Такие треки отмечены меткой `PROTECTED` и пропускаются при воспроизведении.
- Приложение использует тот же внутренний интерфейс, что и сайт soundcloud.com. Если SoundCloud что-то в нём
  изменит, в приложении появится сообщение об ошибке с кнопкой **Retry**. Если повтор не помогает, стоит
  проверить, не вышла ли [новая версия](../../releases/latest).
