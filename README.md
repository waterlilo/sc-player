# sc player

Десктопный клиент SoundCloud для Windows: лайки, плейлисты и любые публичные профили — без рекламы.

## Установка

1. На странице [последнего релиза](../../releases/latest) необходимо скачать один из файлов:
   - `sc-player-setup-v….exe` — установщик (создаёт ярлыки на рабочем столе и в меню «Пуск»);
   - `sc-player-portable-v….exe` — версия, которая запускается без установки.
2. Приложение не подписано сертификатом, поэтому при первом запуске Windows может показать сообщение
   «Windows защитила ваш компьютер». В этом случае следует нажать **Подробнее → Выполнить в любом случае**.
3. Для доступа к своей библиотеке нужно нажать **Sign in to SoundCloud** и войти в аккаунт SoundCloud
   (email и пароль) — после этого появятся лайки и плейлисты пользователя.
   Без входа можно открыть любой публичный профиль, вставив ссылку вида `https://soundcloud.com/…`.

Для обновления достаточно скачать новую версию и установить её поверх текущей — вход и настройки сохраняются.

## Возможности

- Лайки, плейлисты (собственные и понравившиеся), альбомы, история прослушивания, поиск треков с историей запросов.
- Профили: треки, лайки и плейлисты любого пользователя; профили можно закрепить в боковой панели.
- Страница трека: описание, теги, статистика и похожие треки. Правый клик по треку открывает меню действий.
- Подмена защищённых треков: если SoundCloud отдаёт трек только с DRM-защитой или 30-секундным фрагментом,
  приложение ищет на SoundCloud другую загрузку той же записи и проигрывает её (метка `ALT`).
- Честное перемешивание: в случайном порядке перемешивается весь плейлист или все лайки целиком, а не только
  ближайшие треки.
- Автопилот: когда список закончился, воспроизведение продолжается похожими треками (отключается в настройках).
- Перемотка по вейвформе, очередь с перетаскиванием, повтор, кроссфейд, 10-полосный эквалайзер с пресетами,
  выбор устройства вывода.
- Работа в фоне: сворачивание в трей, глобальные горячие клавиши, уведомления о смене трека, автозапуск с Windows.
- Обновление из приложения: установленная версия сама сообщает о выходе новой и устанавливает её.
- Каждая страница сохраняет выбранную вкладку, фильтр и положение прокрутки.
- Скрытие треков: блокировка исполнителей и скрытие по ключевым словам.
- Пока окно свёрнуто или скрыто, анимации полностью останавливаются — продолжает работать только звук.

## Ограничения

- Часть треков SoundCloud отдаёт только в зашифрованном виде (DRM — как правило, монетизированные и
  мейджор-релизы). Для них приложение ищет другую загрузку той же записи; если её нет, трек отмечается меткой
  `PROTECTED` и пропускается.
- Приложение использует тот же внутренний интерфейс, что и сайт soundcloud.com. Если SoundCloud что-то в нём
  изменит, в приложении появится сообщение об ошибке с кнопкой **Retry**. Если повтор не помогает, стоит
  проверить, не вышла ли [новая версия](../../releases/latest).
- В России сайт soundcloud.com заблокирован: для работы приложения нужен zapret, VPN или прокси (прокси можно
  указать в настройках). Гайд сообщества по zapret:
  [«Как починить SoundCloud с помощью zapret»](https://github.com/Flowseal/zapret-discord-youtube/issues/7449).
